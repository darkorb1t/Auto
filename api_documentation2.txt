Developers

API Reference

Integrate seamlessly with the Excalibur Shop Bot platform. Use our RESTful endpoints to check your balance, monitor live product stock, and automate your purchases in real-time.

Authentication

Every API request requires your unique API Key to be passed via the
X-API-Key
HTTP header.

X-API-Key

Keep your API Key secret. If compromised, revoke it immediately via the Telegram Bot.

Rate Limits

To ensure platform stability, all API endpoints are rate-limited to
3 requests per second
per API Key.

If you exceed this limit, the API will respond with HTTP status
429 Too Many Requests
.

429 Too Many Requests

Code Examples

Use the snippets below to easily integrate the automated ordering endpoint into your application.

curl -X POST https://arrsnetworkzone.in/api/v1/order ^
  -H "X-API-Key: AK_YOUR_SECRET_KEY" ^
  -H "Content-Type: application/json" ^
  -d "{\"service_id\": \"S_01\", \"quantity\": 1}"
